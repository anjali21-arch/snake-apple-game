# 🐍 Full Screen Snake Game (Java)

A classic Snake Game built using Java Swing with a modern full-screen experience, smooth controls, and interactive UI.

---

## 🎮 Features

- 🖥️ Full-screen gameplay experience
- 🐍 Smooth snake movement
- 🍎 Random apple generation
- 📈 Live score tracking
- 💀 Game over screen
- 🔁 Restart button
- ❌ Exit button
- ⌨️ Keyboard controls (Arrow keys)

---

## 🚀 How to Run

1. Make sure Java is installed on your system  
2. Compile the program:
   ```bash
   javac SnakeGameFullScreen.java
